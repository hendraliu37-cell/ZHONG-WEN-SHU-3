# Zhongwen Shu Installers

This folder mirrors the release artifacts so they can be browsed directly from
the GitHub repository file list.

- `android/ZhongwenShu.apk`: Android installer.
- `windows/ZhongwenShu-Windows-Setup-v1.0.0.exe`: Windows setup installer.
- `windows/ZhongwenShu-Windows-Portable-v1.0.0.zip`: Windows portable build.

If Windows blocks the setup installer because it is unsigned, use the portable
zip: extract it, then run `zhongwen_shu.exe`.
